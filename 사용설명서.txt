================================================================================
  LOREWAY TOOLKIT (마비노기 제작 최적화 도구) - 사용자 설명서 (Manual)
================================================================================

본 프로그램은 마비노기에서 장비 및 아이템 제작 시,
[NEXON Open API 실시간 경매장 시세]와 [NPC 상점 / 모험가의 인장 등 특수 재화 교환]을
자동으로 비교 분석하여 '가장 저렴한 최소 비용 조달 경로'와 '예상 절감 비용'을
계산해 주는 스마트 의사결정 지원 도구입니다.


--------------------------------------------------------------------------------
1. NEXON Open API Key 발급 및 등록 방법
--------------------------------------------------------------------------------

[1단계] API Key 무료 발급받기
  1. 웹 브라우저를 열고 넥슨 오픈 API 공식 포털에 접속합니다.
     ▶ 주소: https://openapi.nexon.com
  2. 넥슨 계정으로 로그인합니다.
  3. 상단 메뉴에서 [마이페이지] → [애플리케이션 관리] 또는 [API 신청]으로 이동합니다.
  4. 대상 게임으로 [마비노기 (Mabinogi)]를 선택합니다.
  5. 애플리케이션 이름(예: LorewayTest)을 입력하고 등록을 완료하면,
     영어와 숫자로 구성된 고유 API Key(예: test_xxxxxxxxxxxxxxxxx)가 발급됩니다.
  6. 발급받은 키를 복사합니다.

[2단계] 프로그램에 API Key 등록하기
  1. LorewayToolkit 폴더 안에 있는 '.env.example' 파일을 찾습니다.
  2. '.env.example' 파일의 이름을 '.env' 로 변경합니다.
     (이미 .env 파일이 있다면 해당 파일을 메모장으로 엽니다.)
  3. 메모장으로 '.env' 파일을 열고 다음과 같이 본인의 키를 붙여넣고 저장(Ctrl+S)합니다.

     NEXON_API_KEY=여기에_발급받은_키_붙여넣기

  ★ 꿀팁 (API Key가 없어도 실행 가능!):
     API Key가 없거나 발급받기 전이더라도, 프로그램 내부에 기본 시세 캐시 데이터가
     내장되어 있어 모든 제작 최적화 계산 기능을 100% 정상 체험할 수 있습니다.


--------------------------------------------------------------------------------
2. 프로그램 실행 및 윈도우 보안 경고 해결 방법
--------------------------------------------------------------------------------

[기본 실행]
  1. 'LorewayToolkit.exe' 파일을 더블 클릭하여 실행합니다.
  2. .NET 런타임이나 별도의 프로그램을 설치할 필요 없이 즉시 실행됩니다.
  3. 창 크기는 한눈에 보기 편하도록 1120 x 780 해상도로 자동 고정됩니다.

[★ 처음 실행 시 "Windows의 PC 보호" 파란색 보안 창이 뜰 때 해결법]
  - 원인: 
    개인 개발자가 만든 포트폴리오용 프로그램이라 수백만 원짜리 기업용 공인 유료 
    전자서명(Code Signing)이 등록되어 있지 않아 윈도우(SmartScreen)가 처음 1회 
    확인 창을 띄우는 정상적인 현상입니다. (바이러스가 아니니 안심하셔도 됩니다!)

  - 해결 방법 (1초 해결):
    1. 파란색 경고 창에서 밑줄 그어진 **[추가 정보]** 글씨를 클릭합니다.
    2. 화면 우측 하단에 새롭게 나타나는 **[실행]** 버튼을 클릭합니다.
    (이후부터는 경고 없이 즉시 정상 실행됩니다.)

  - 또 다른 영구 해제 방법:
    'LorewayToolkit.exe' 마우스 우클릭 → [속성] 클릭 → 맨 아래 보안 항목의
    [차단 해제(Unblock)] 체크박스에 체크한 뒤 [확인]을 누르면 영구 해제됩니다.

  ※ 주의: 
     실행 파일과 함께 제공되는 'Data' 폴더와 '.env' 파일은 항상 
     LorewayToolkit.exe와 같은 폴더 안에 함께 있어야 합니다.


--------------------------------------------------------------------------------
3. 프로그램 주요 기능 사용법
--------------------------------------------------------------------------------

[기능 1] 제작 목표 아이템 선택
  - 상단 드롭다운 메뉴(ComboBox)를 클릭하여 제작하고자 하는 목표 아이템을 선택합니다.
    (예: 페러시우스 타이탄 블레이드, 찬란한 기억의 결정 등)
  - 선택 즉시 하단에 해당 아이템을 만드는 데 필요한 모든 1차/하위 재료와
    필요 수량이 일목요연하게 표시됩니다.

[기능 2] 실시간 경매장 시세 조회 및 새로고침
  - [시세 새로고침] 버튼을 누르면 넥슨 경매장 API와 통신하여 현재 등록된 최저 매물 가격을 
    자동으로 불러옵니다.
  - 네트워크 부하 및 API 호출 제한을 방지하기 위해 '10분 캐싱'이 작동합니다.
    10분 이내에 이미 조회한 재료는 로컬 캐시에서 즉시 불러와 빠르게 처리됩니다.

[기능 3] 보유 재료(인벤토리) 입력
  - 각 재료 목록 옆의 '보유 수량' 입력 칸에 현재 내 캐릭터 가방에 가지고 있는 
    재료 개수를 입력합니다.
  - 이미 가지고 있는 재료만큼 부족 수량이 자동으로 차감되어, 추가로 구매/수급해야 
    할 진짜 비용만 실시간으로 재계산됩니다.

[기능 4] 다단계 제작 비용 최적화 계산
  - 프로그램이 재료별로 다음 수급 경로를 정밀 비교합니다:
    * 경로 A: 넥슨 경매장에서 완제품 재료를 골드로 직접 구매
    * 경로 B: NPC 상점 또는 모험가의 인장 등 특수 재화로 확정 교환
  - 더 저렴한 쪽을 '추천 수급처'로 자동 선정하고, 경매장 직구매 대비 
    얼마를 절약할 수 있는지(예: "420,000 Gold 절감 예상")를 초록색 뱃지로 표시합니다.

[기능 5] 나만의 커스텀 레시피 등록
  - 우측 상단 [신규 레시피 등록] 버튼을 클릭하면 팝업 창이 나타납니다.
  - 새로운 아이템 이름과 필요한 재료 목록 및 수량을 입력하고 저장하면,
    'user-recipes.json' 파일에 영구 저장되어 언제든 다시 불러올 수 있습니다.


--------------------------------------------------------------------------------
4. 자주 묻는 질문 및 문제 해결 (Troubleshooting)
--------------------------------------------------------------------------------

Q1. "시세 조회 실패 / 이전 시세 유지" 메시지가 뜹니다.
  A: 넥슨 서버 점검 중이거나 일시적인 네트워크 지연, 혹은 API Key 오입력일 수 있습니다.
     프로그램은 사용자의 작업을 방해하지 않기 위해 마지막으로 조회된 정상 시세를
     유지해 주므로 안심하고 계속 작업하셔도 됩니다.

Q2. 경매장에 매물이 아예 없는 희귀 재료는 어떻게 계산되나요?
  A: 매물이 없어 가격을 알 수 없는 재료는 0원으로 왜곡 처리하지 않고,
     '시세 미확인' 상태로 안내하여 사용자가 혼란을 겪지 않도록 안전하게 배제합니다.

Q3. 다른 컴퓨터로 프로그램을 옮기고 싶어요.
  A: 'LorewayToolkit' 폴더 전체를 USB나 압축 파일로 복사하여 다른 PC로 가져가면
     아무런 설정 없이 바로 더블 클릭하여 실행할 수 있습니다.
  A2: GitHub 저장소(https://github.com/PhorinKid/LorewayToolkit)에서 
      코드를 클론하여 작업하실 경우, 함께 들어있는 'AI_CONTEXT.md' 파일을 통해 
      어느 AI 어시스턴트에게든 작업을 바로 인수인계할 수 있습니다.
